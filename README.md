# 💼 Freelance Hourly & Project Rate Calculator

An interactive, privacy-first, zero-login micro-tool engineered to calculate accurate freelance hourly rates, daily rates, and project quotes based on financial goals, overhead expenses, taxes, billable capacity, and profit buffers.

## 🚀 Key Features

- **Reverse-Engineered Pricing:** Calculates required gross revenue starting from desired net take-home salary.
- **Billable Time Adjustment:** Factors in non-billable administrative hours (typically 30-40% for freelancers).
- **Tax Pre-Grossing:** Accurately pre-tax grossing for self-employment tax + federal/state liabilities.
- **Time Off Accounting:** Includes vacation, public holidays, and sick days.
- **Project Quote Generator:** Dynamic quote generator with risk & complexity multipliers.
- **Visual Revenue Bar Chart:** Real-time breakdown showing where every dollar goes (Net, Tax, Overhead, Profit).
- **Dark Mode Glassmorphism UI:** Modern, responsive design system optimized for desktop and mobile devices.
- **Zero External Dependencies:** Built with pure vanilla HTML5, CSS3, and modern JavaScript.

## 🛠️ Installation & Usage

Simply open `index.html` in any web browser or host static files on Vercel, Netlify, or GitHub Pages.

```bash
git clone https://github.com/username/freelance-rate-calculator.git
cd freelance-rate-calculator
# Open index.html directly in browser
```
